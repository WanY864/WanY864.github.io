## Goal

The goal of this lab is to install the Unity development environment and create a first working 3D project.

## Planned Process

1. Install Unity Hub.
2. Configure the Unity Editor installation directory on drive `D:`.
3. Install a stable Unity Editor version.
4. Create a new 3D project.
5. Add a simple 3D object to the scene.
6. Change its position, rotation, and scale.
7. Enter Play Mode and verify that the project runs correctly.
