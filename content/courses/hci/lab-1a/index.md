## Goal

The goal of this lab is to create an online course portfolio that can be updated throughout the semester.

I chose **Hugo** as the static site generator and **Blowfish** as the theme because I wanted the site to remain lightweight, readable, and easy to extend for future coursework.

## Approach

My planned workflow is:

1. Install Hugo Extended and Git.
2. Create the site on a dedicated development folder.
3. Install Blowfish as a Git submodule.
4. Configure the language, navigation, homepage, and article layout.
5. Create a Human-Computer Interaction course section.
6. Add Homework 1 and the first lab entries.
7. Preview the website locally with `hugo server -D`.
8. Publish the repository through GitHub Pages.

## Design Direction

I wanted the site to feel more like a **course portfolio** than a generic personal blog. The visual direction is intentionally restrained:

- white background,
- generous spacing,
- content-focused article pages,
- a small amount of blue used for section separators and navigation emphasis,
- and a table of contents for longer homework posts.
